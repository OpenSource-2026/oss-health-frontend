# OSS Health Checker Frontend

OSS Health Checker의 프론트엔드 레포지토리입니다.

이 프로젝트는 GitHub 레포지토리 URL을 입력받아 오픈소스 프로젝트의 건강도를 시각적으로 보여주는 웹 애플리케이션입니다.
사용자는 레포지토리를 분석한 뒤 종합점수, 차원별 점수, 상세 분석, AI 개선 제안을 한눈에 확인할 수 있습니다.

---

## 1. 프로젝트 소개

OSS Health Checker는 오픈소스 프로젝트의 상태를 단순한 Star 수나 Fork 수 만으로 판단하지 않고 다음 5가지 평가 차원을 기준으로 오픈소스의 건강도를 분석하는 서비스입니다.

- 커뮤니티 활성도
- 지속 가능성
- 코드 품질 및 신뢰성
- 법적/운영 거버넌스
- 프로젝트 성숙도

프론트엔드는 사용자가 GitHub URL을 입력하고 분석 결괄르 쉽고 직관적으로 이해할 수 있는 웹 페이지 화면을 구성하는 역할을 담당합니다.

---

## 2. 주요 기능

### 메인 페이지
- 서비스 소개 문구 제공
- GitHub 레포지토리 URL 입력 폼 제공
- 분석 시작 버튼 제공
- 분석 진행 중 로딩 화면 표시
- 5개 평가 차원 소개 섹션 제공
- 상단 메뉴바 및 사이드바 네비게이션 제공

### 결과 대시보드
- 종합 건강도 점수 표시
- 등급(A/B/C/D/F) 표시
- 5개 평가 차원 점수 시각화
- 레이더 차트 제공
- 차원별 개별 점수 카드 제공
- 상세 분석 페이지 이동 기능 제공

### 상세 분석 페이지
- 각 평가 차원별 상세 설명 제공
- 점수 범위에 따른 상태 해석 제공
- AI 기반 개선 제안 표시
  - Positive Signals
  - Negative Signals

---

### 3. 기술 스택

- React: 컴포넌트 기반 사용자 인트페이스 구현
- Tailwind CSS: 빠르고 일관된 UI 스타일링
- Chart.js: 건강도 점수 시각화
- Axios or Fetch API: 백엔드 API 통신
- Docker: 실행 환경 통일

## 4. 예상 화면 구성

### 4.1 메인 페이지
**구성 요소**
- 서비스 이름 및 한줄 소개

- 분석 시작 버튼
- 로딩 UI
- 5개 평가 차원 소개 섹션

**구성 요소**

- Average Score 영역
- 차원별 점수 카드
- 상세 보기 버튼

### 4.3 결과 2페이지 - 차원별 상세 분석
**구성 요소**
- 5개 평가 차원 상세 카드
- AI 개선 제안 영역
- 강점 / 개선점 구분 표시
