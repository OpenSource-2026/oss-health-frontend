# OSS Health Checker Frontend

OSS Health Checker의 프론트엔드 레포지토리입니다.

이 프로젝트는 GitHub 레포지토리 URL을 입력받아 오픈소스 프로젝트의 건강도를 시각적으로 보여주는 웹 애플리케이션입니다.
사용자는 레포지토리를 분석한 뒤 종합점수, 차원별 점수, 상세 분석, AI 개선 제안을 한눈에 확인할 수 있습니다.

---

## 1. 프로젝트 소개

OSS Health Checker는 오픈소스 프로젝트의 상태를 단순한 Star 수나 Fork 수 만으로 판단하지 않고 다음 5가지 평가 차원을 기준으로 오픈소스의 건강도를 분석하는 서비스입니다.

- 커뮤니티 활성도
- 지속 가능성
- 코드 품질 및 신뢰성
- 법적/운영 거버넌스
- 프로젝트 성숙도

프론트엔드는 사용자가 GitHub URL을 입력하고 분석 결과를 쉽고 직관적으로 이해할 수 있는 웹 페이지 화면을 구성하는 역할을 담당합니다.

---

## 2. 주요 기능

### 메인 페이지
- 서비스 소개 문구 제공
- GitHub 레포지토리 URL 입력 폼 제공
- 분석 시작 버튼 제공
- 분석 진행 중 로딩 화면 표시
- 5개 평가 차원 소개 섹션 제공
- 상단 메뉴바 및 사이드바 네비게이션 제공

### 결과 대시보드
- 종합 건강도 점수 표시
- 등급(Excellent / Good / Moderate / Weak / Risk) 표시
- 5개 평가 차원 점수 시각화 (레이더 차트 + 막대 비교)
- 차원별 개별 점수 카드 제공
- 차원별 강점/위험 신호 및 개선 제안 TOP 3
- AI 분석 리포트 표시 (Gemini, 키가 있을 때)

### 부가 기능
- **PDF 저장**: 결과 화면을 A4 PDF로 저장 (브라우저 인쇄, 웹·모바일 모두)
- **QR 폰 공유**: 결과 화면의 QR을 폰으로 스캔하면 같은 결과를 폰에서 그대로 확인 (재분석 없음)
- **다크 모드**: 라이트/다크 테마 토글 (localStorage에 저장)
- **예시 레포**: 분석 화면에서 클릭 한 번으로 예시 저장소 입력

---

### 3. 기술 스택

- React + Vite: 컴포넌트 기반 UI / 빠른 빌드·HMR
- CSS (디자인 토큰 + CSS 변수): 라이트·다크 테마 스타일링
- Chart.js (react-chartjs-2): 건강도 레이더 차트
- qrcode.react: 결과 공유 QR 생성
- Fetch API: 백엔드 API 통신
- Docker + nginx: 정적 빌드 서빙 및 `/api` 리버스 프록시

---

## 4. 화면 구성

### 4.1 메인 페이지
- 서비스 이름 및 한줄 소개
- GitHub URL 입력창 + 분석 시작 버튼
- 분석 진행 중 로딩 UI
- 5개 평가 차원 소개 섹션 (상단 메뉴로 차원별 이동)

### 4.2 결과 화면 (단일 스크롤 대시보드)
- 분석 대상 레포지토리 URL / 종합 점수(Overall Score) + 등급
- 5개 차원 레이더 차트 + 막대 비교
- 차원별 점수 카드 (클릭 시 상세 펼침: 강점/위험 신호)
- 개선 제안 TOP 3
- AI 분석 리포트 (Gemini 키가 있을 때)
- 우측 하단: PDF 저장 · QR 폰 공유 · 다크 모드 토글

---

## 5. 실행 방법

```bash
# 개발 모드
npm install
npm run dev        # http://localhost:5173

# 프로덕션 빌드
npm run build      # dist/ 생성
```

전체 스택(프론트 + 백엔드 + 분석 엔진)은 프로젝트 루트의 `docker compose up --build`로 한 번에 실행할 수 있습니다. 백엔드 주소는 `.env`의 `VITE_API_BASE_URL`로 설정합니다 (예: `http://localhost:8000`).
